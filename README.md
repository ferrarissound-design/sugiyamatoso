# 杉山塗装 Webサイト

Web制作練習用に制作した、架空の住宅塗装会社「杉山塗装」のコーポレートサイトです。

## コンセプト

- 静岡県西部の地域密着型塗装店
- ベテラン職人が多数在籍
- 現地調査・見積もり無料
- 外壁塗装・屋根塗装・付帯部塗装に対応

## ページ構成

- `index.html` : トップページ
- `company.html` : 会社案内
- `president.html` : 代表あいさつ
- `works.html` : 施工事例
- `contact.html` : お問い合わせ・FAQ
- `404.html` : 404ページ
